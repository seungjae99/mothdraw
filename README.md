# Mothdraw

TypeScript와 SVG로 만드는 가상의 나방 표본 도감. 시드 하나가 실루엣과 무늬를 함께 결정합니다. 작업 전 [개발 가이드라인](./DEVELOPMENT.md)을 읽어주세요.

## 실행

Node.js 22.12 이상과 npm이 설치된 환경:

```sh
npm ci
npm run dev
```

현재 Mac에서는 Codex에 포함된 Node.js v24.19.0과 프로젝트 로컬 npm 10.9.2를 사용할 수 있습니다. 시스템 설정을 변경하지 않았습니다.

```sh
cd /Users/choi/dev/proj/mothdraw
./scripts/npm.sh run dev
```

이 래퍼는 일반 npm이 있으면 우선 사용합니다. Codex 런타임 경로는 이 Mac 전용이며, 다른 환경에서는 Node.js와 npm을 설치하세요. 로컬 npm은 `.tooling/`에 설치되어 버전 관리에서 제외됩니다.

## 검증

```sh
./scripts/npm.sh run check
./scripts/npm.sh test
./scripts/npm.sh run build
```

테스트는 고정 20개, 추가 200개 시드, 다이얼 양 끝 72개에 대해 결정성, 좌표 범위, 닫힌 윤곽, 날개 자체 교차, 뿌리 위치와 좌우 대칭을 검사합니다. 무늬는 소속 날개 안에 있는지, 뒷날개 선이 앞날개를 관통하지 않는지, 무늬는 좌우 대칭이고 질감은 좌우가 다른지, 선 개수가 상한 안인지 확인합니다. 옵션은 정규화와 재현성을, 애니메이션은 가짜 DOM 위에서 모든 선이 정확히 한 번씩 손 순서대로 그려지는지와 건너뛰기·취소·동작 축소를 확인합니다. esbuild는 테스트와 표본 도판 스크립트에서 TypeScript를 실행 가능한 모듈로 변환하는 개발 의존성입니다.

## 화면

표본 한 마리만 보여줍니다. 시드와 세 가지 설정을 정하고 그리기를 누르면, 그려지는 과정이 애니메이션으로 재생됩니다.

- **형태** — 다섯 계열 중 하나를 고르거나 시드에 맡깁니다. 계열마다 날개맥 수, 띠의 기울기와 물결, 눈알무늬 확률이 다릅니다.
- **무늬 밀도** — 날개맥, 띠, 음영, 해칭, 점, 가장자리 털의 양.
- **기묘함** — 선의 떨림, 비율의 과장, 눈알무늬 크기, 몸통 털, 가장자리 손상. 0이면 손상이 전혀 없습니다.

두 슬라이더의 가운데가 기준값이며, 도판과 같은 결과를 냅니다. 그리는 중에 화면을 누르거나 Esc를 누르면 바로 완성됩니다. `prefers-reduced-motion`이면 애니메이션 없이 완성본이 나옵니다.

시드와 설정은 URL 해시에 실립니다. 링크를 열면 같은 표본이 다시 나옵니다.

- 개체마다 크기, 날개 쌍 개수, 더듬이 길이, 몸통 비율이 다릅니다. 날개가 두 쌍이 아니면 아래 줄에 표시됩니다.
- `u`는 생성 좌표계의 너비이며 실제 생물의 물리적 길이가 아닙니다.
- 여러 마리를 늘어놓고 비교하려면 아래 도판 스크립트를 씁니다.
- 수집 기능과 표본함은 만들지 않습니다. 표본을 남기는 수단은 URL과 SVG 저장입니다.

## 비교 도판 생성

```sh
./scripts/npm.sh run plate -- ./artifacts
```

무늬, 실루엣, 구조 도판과 100개 조사 도판을 독립 SVG로 생성합니다. 브라우저에서 바로 열 수 있으며 서버가 필요하지 않습니다. `artifacts/`는 버전 관리에서 제외됩니다.

## 생성기 변경 기록

### 0.6.0 — 변주

한 종류를 반복해 찍어내던 문제를 네 축으로 풀었습니다.

- **전체 크기** — 개체마다 0.62에서 1.15배. 프레임은 고정이라 작은 개체는 작게 보입니다. `size`로 결과에 실립니다.
- **날개 쌍 개수** — 한 쌍, 두 쌍, 세 쌍. 날개는 뒤에서 앞으로 쌓인 쌍의 목록이 되었고, 각 쌍은 자기 앞의 모든 쌍에 가려집니다. 한 쌍짜리는 날개가 더 아래로 처지고, 세 쌍짜리는 뒷날개 밑으로 여분의 쌍이 삐져나옵니다. 기묘함 0에서는 항상 두 쌍입니다.
- **더듬이 길이** — 넷 중 하나꼴로 날개를 한참 넘어서는 길이가 나옵니다. 길수록 빗살은 짧아져 덤불이 아니라 가느다란 촉수로 읽힙니다.
- **머리·가슴·배** — 가슴 길이, 머리 크기와 높이, 배의 폭·길이·테이퍼가 각각 따로 결정됩니다. 배는 타원이 아니라 윤곽선으로 만들어, 뭉툭한 구더기부터 긴 바늘까지 나옵니다. 날개 경첩, 다리 위치, 더듬이 뿌리는 모두 가슴 치수에서 파생됩니다.

프레임을 340×260에서 380×320으로 넓혔습니다. 구조 난수의 추출 순서가 바뀌었으므로 0.5.0 이전의 실루엣은 재현되지 않습니다.

측정: 표본 한 마리 생성 3.7ms, 표본당 선 약 751개 (Node.js v24.19.0, Apple Silicon).


### 0.5.0 — 옵션과 그리기 화면

`generateMoth(seed, options)`로 형태 계열, 무늬 밀도, 기묘함을 받습니다. 옵션은 정규화해 0.01 단위로 고정하고 결과에 함께 실어, seed와 options와 generatorVersion만 있으면 같은 표본이 그대로 재현됩니다. 모든 배율은 두 슬라이더의 가운데에서 정확히 1이며, 기본값은 0.4.0과 바이트 단위로 같은 형상을 냅니다.

화면을 도감에서 단일 표본으로 바꾸고, 그려지는 과정을 애니메이션으로 재생합니다. 겹침 순서와 그리는 순서를 분리해 윤곽부터 긋고 질감으로 끝내며, 길이를 기준으로 등속 진행합니다. 약 5초, 314프레임입니다.

측정: 표본 한 마리 생성 3.5ms, 표본당 선 약 736개 (Node.js v24.19.0, Apple Silicon).


### 0.4.0 — 거친 선과 불쾌함

면 채움을 없애고 선으로만 그립니다. 윤곽은 `edge` 레이어의 마크가 되어 다른 무늬와 똑같이 가림 처리를 받으므로, 채움 없이도 앞·뒷날개 겹침이 유지됩니다. 모든 선에 주기적 노이즈로 떨림을 주고 윤곽은 두 번 긋습니다. 떨림은 자르기 전에 적용해 포함 관계가 정확히 유지됩니다.

겹눈, 다리 세 쌍, 몸통을 뚫고 나오는 털, 띠에 붙는 짙은 음영 덩어리, 좌우 비대칭인 가장자리 손상을 추가했습니다. 손상은 구멍 다각형으로 처리해 무늬와 털과 윤곽을 한꺼번에 잘라냅니다. `torn`으로 어느 날개가 손상됐는지 알 수 있습니다.

좌우 대칭 계약이 바뀌었습니다. 무늬는 여전히 정확히 대칭이지만, 손상된 날개 쌍은 비교 대상에서 제외합니다. DEVELOPMENT.md가 마모와 미세 질감의 비대칭을 허용하는 범위입니다.

대표 시드: `nocturne-003`(짙은 덩어리), `nocturne-019`(찢어진 앞날개), `nocturne-001`(손상과 음영), `nocturne-004`(옅은 개체).

측정: 표본 한 마리 생성 3.5ms, 표본당 선 약 676개 (Node.js v24.19.0, Apple Silicon). 목표인 200ms 안입니다.


### 0.3.0 — 선화와 무늬

날개맥, 띠, 눈알무늬, 해칭, 점, 가장자리 털, 몸통 주름을 추가했습니다. 실루엣은 `structure` 난수 스트림을 그대로 쓰므로 0.2.0과 동일하며, 무늬는 `pattern`, 질감은 `texture` 스트림을 사용합니다.

대표 시드: `nocturne-013`(둥근, 큰 눈알무늬), `nocturne-019`(긴 꼬리, 뒷날개 눈알무늬), `nocturne-004`(후퇴한, 옅은 무늬), `nocturne-020`(물결, 다중 띠).

띠는 처음에 v 고정으로 그려 윤곽과 평행한 등고선처럼 보였습니다. 기울기를 주고 양 끝이 날개 가장자리에 닿도록 바꿔 실제 나방의 횡선에 가깝게 조정했습니다. 날개맥도 한 점으로 수렴해 방사형으로 보여, 시작 위치를 뿌리에서 떼고 좌우 휨을 더했습니다.

측정: 표본 한 마리 생성 1.8ms, 표본당 선 약 308개 (Node.js v24.19.0, Apple Silicon). 목표인 200ms 안입니다.
